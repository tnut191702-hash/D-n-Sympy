Thư viện SymPy

  • Thư viện mã nguồn mở cho toán học ký hiệu (symbolic)
  • Là hệ đại số máy tính CAS, tương tự Mathematica, Maple, Wolfram Alpha
  • Chỉ cần biết Python, không phải học ngôn ngữ riêng
  • Xử lý biểu thức nguyên bản: rút gọn, giải phương trình, đạo hàm, tích phân
  • Kiểm chứng kết quả & khuyến khích tư duy khám phá

Bất phương trình bậc nhất hai ẩn

ax + by ≤ c  (hoặc ≥, <, >)
a, b, c ∈ ℝ; a, b không đồng thời bằng 0
  • Nghiệm: cặp (x₀; y₀) làm bất đẳng thức đúng → luôn có vô số nghiệm
  • Miền nghiệm: tập các điểm có tọa độ là nghiệm
  • Ví dụ: 2x + 3y < 1 ✔  |  2x² + 3y < 1 ✘ (x bậc hai)

Cách xác định miền nghiệm

Đường thẳng d: ax + by = c chia mặt phẳng thành hai nửa mặt phẳng bờ d.

Bước 1
Vẽ đường thẳng d
Bước 2
Lấy điểm M₀ ∉ d (thường là O(0;0))
Bước 3
Tính ax₀ + by₀, so sánh với c
Bước 4
Kết luận nửa mặt phẳng là miền nghiệm; gạch phần còn lại

Hệ bất phương trình bậc nhất hai ẩn

  • Gồm từ hai bất phương trình bậc nhất hai ẩn trở lên
  • Nghiệm: cặp (x₀; y₀) thỏa đồng thời mọi bất phương trình
  • Nguyên tắc: miền nghiệm của hệ = giao các miền nghiệm thành phần
Cách làm: biểu diễn từng bất phương trình → gạch phần không thuộc miền nghiệm → phần còn lại (thường là đa giác) là miền nghiệm của hệ

Nhược điểm của SymPy

  • Tốc độ xử lý chậm: phải duy trì cấu trúc đại số → tốn tài nguyên
  • Kém hiệu quả với bài toán quy mô lớn so với NumPy, SciPy
  • Thiếu thuật toán chuyên sâu cho tối ưu công nghiệp (hàng trăm ràng buộc) → dùng PuLP, SciPy
SymPy phù hợp: nền tảng lý thuyết & bài toán cơ bản, giáo dục.
Chương II · Giải thích câu lệnh

(1) symbols() và Eq()

Khai báo biến

x, y = symbols('x y')
  • x, y là biến ký hiệu, chưa có giá trị cụ thể
  • Phép toán lưu dưới dạng biểu thức đại số

Tạo phương trình

Eq(x + y, 10)
  • Tạo đường thẳng biên x + y = 10 từ x + y ≤ 10
  • Dùng để tìm giao điểm ở bước sau

(2) And() và solve()

And() – phép giao

And(dk1, dk2, ...)
  • Gộp các điều kiện phải xảy ra đồng thời
  • Có thể dùng ký hiệu &

solve() – giải hệ

solve([d1, d2], (x, y))
# {x: 20, y: 80}
  • Tìm tọa độ đỉnh = giao điểm các đường biên
  • Trả về dictionary, chính xác tuyệt đối

(3) plot_implicit()

plot_implicit(he, (x, min, max), (y, min, max))
  • Quét mặt phẳng Oxy trong khoảng giới hạn của x và y
  • Tự động tô màu vùng thỏa hệ bất phương trình
  • Mô phỏng thao tác “gạch bỏ phần không thuộc miền nghiệm”

Phụ trợ: vòng lặp for duyệt cặp đường thẳng · if lọc đỉnh hợp lệ · set() loại đỉnh trùng

Chương III · Ứng dụng 1

Biểu diễn miền nghiệm – SGK Toán 10

import sympy as sp

# 1. Khai báo 2 ẩn x và y
x, y = sp.symbols('x y')

# ==========================================
# 2. BIỂU DIỄN MIỀN NGHIỆM CHO HỆ a)
# y - x < -1; x > 0; y < 0
# ==========================================
he_a = sp.And(y - x < -1, x > 0, y < 0)
# Vẽ hệ a với giới hạn trục x từ -2 đến 6, y từ -6 đến 2
do_thi_a = sp.plot_implicit(he_a, (x, -2, 6), (y, -6, 2), 
                            title="Mien nghiem he a", show=False)

do_thi_a.show()

And: gộp hệ · plot_implicit: tô miền nghiệm · show(): hiển thị đồ thị · Hệ b) x ≥ 0; y ≥ 0; 2x + y ≤ 4 và c) x ≥ 0; x + y > 5; x − y < 0 viết tương tự

Code SymPy & Kết quả

x, y = sp.symbols('x y')
he = sp.And(20*x + 10*y <= 1200,
            x + y <= 100, x >= 0, y >= 0)
P = sp.solve([20*x + 10*y - 1200,
              x + y - 100], (x, y))
F = (3.5*x + 2*y).subs(P)
print(P, F)
sp.plot_implicit(he, (x, -10, 110),
                 (y, -10, 130))
